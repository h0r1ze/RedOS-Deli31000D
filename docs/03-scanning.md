# Шаг 3. Сканирование

Сканер — отдельное устройство внутри того же корпуса, со своим
USB-интерфейсом и своим протоколом. Печать и сканирование настраиваются
независимо: одно может работать, другое нет.

## Порядок проверки

Идти сверху вниз, первый сработавший вариант и есть ответ.

### 1. IPP-over-USB (eSCL) — если повезло

Если `tools/deli-asp-probe.py` показал интерфейс класса **`07/01/04`**,
драйвер не нужен вовсе:

```sh
dnf install -y ipp-usb sane-airscan
systemctl enable --now ipp-usb
scanimage -L
```

Сканер появится как `airscan:...`. Это же включает и печать без PPD.

### 2. Сетевой аппарат — тоже без драйверов

Модели с сетью и Wi-Fi (`M3100DN`, `M3100DW`) обычно поддерживают eSCL или
WSD. Если аппарат в сети:

```sh
dnf install -y sane-airscan
scanimage -L
airscan-discover                 # покажет найденные адреса
```

Ничего не нашлось — значит, по сети сканер не отдаётся, возвращаемся к USB.

### 3. Протокол ASP (основной путь для USB)

```sh
sudo ./tools/deli-asp-probe.py
```

Скрипт шлёт сканеру кадр «заблокировать» — 32 байта big-endian с сигнатурой
`ASP\x01` — и смотрит на ответ. Протокол разобран в проекте
[pantum-open](https://github.com/loss-and-quick/pantum-open) для Pantum
M6500; аппараты этого класса часто оказываются роднёй.

**Ответ с сигнатурой `ASP` и осмысленными настройками** — ставим backend:

```sh
sudo ./install-scanner.sh
scanimage -L
scanimage -d pantum --mode Gray --resolution 300 --format=png -o /tmp/scan.png
```

Что делает `install-scanner.sh`: скачивает pantum-open (коммит `cd25c1d4`),
накладывает `sane/patches/0001-deli-m3100d.patch`, собирает **только**
backend (фильтр печати ему не нужен, значит и jbigkit не нужен), кладёт
`libsane-pantum.so.1` туда, где система держит остальные backends,
`pantum.conf` и `dll.d/pantum` — в `/etc/sane.d`, правило udev — в
`/etc/udev/rules.d`. Машина без сети: скачайте дерево отдельно и укажите
`--source КАТАЛОГ`.

Патч делает две вещи: добавляет идентификатор `300e:10c4` и учит backend
искать сканер в дескрипторе конфигурации, а не считать, что он всегда на
интерфейсе 1 с эндпоинтами `0x02/0x82` (у Deli нумерация другая — интерфейс
принтера первый).

Опции сканирования: `--mode Lineart|Halftone|Gray|Color`,
`--resolution 75|150|300|600|1200`, `--source`, `--threshold`, геометрия
`-l/-t/-x/-y` в миллиметрах.

**Ответ пришёл, но настройки выглядят пустыми или странными.** Backend всё
равно стоит поставить: возможно, поля блока настроек у Deli лежат по другим
смещениям. Первый же скан покажет — например, неверный размер области или
перекос. С отладкой:

```sh
SANE_DEBUG_PANTUM=4 scanimage -d pantum --resolution 150 -o /tmp/t.pnm 2>&1 | tail -40
```

**Ответа нет или сигнатура другая** — протокол не тот, идём дальше.

### 4. Дешёвая проверка: backend xerox_mfp

Многие МФУ китайской сборки повторяют протокол Samsung SCX, который умеет
штатный `xerox_mfp`. Устройств Deli в его таблице нет, но добавить строку —
минута:

```sh
echo 'usb 0x300e 0x10c4' | sudo tee -a /etc/sane.d/xerox_mfp.conf
scanimage -L
```

Не помогло — строку убрать.

### 5. Снять дамп протокола

Если ни один вариант не подошёл, остаётся посмотреть, как со сканером
разговаривает родной драйвер под Windows:

```sh
modprobe usbmon
wireshark -i usbmonN              # N — номер шины из lsusb
```

В pantum-open для такой работы есть готовые инструменты: `proto/usbshim.c`
(перехват вызовов libusb без root), `proto/parse_dump.py` (дамп в одну
строку на кадр), `notes/scan-protocol.md` (полное описание ASP — с ним
удобно сравнивать). Если протокол окажется близким, правка backend обычно
сводится к смещениям в блоке настроек.

## Права доступа

SANE ходит к сканеру напрямую через `/dev/bus/usb/...`, и по умолчанию этот
узел принадлежит root. Правило `sane/99-deli-m3100d.rules` (его ставит
`install-scanner.sh`) выдаёт устройство группе `scanner` и помечает его
меткой `libsane_matched`, по которой штатные правила sane-backends дают
доступ вошедшему в систему пользователю.

Если сканер виден только под root:

```sh
sudo usermod -aG scanner,lp ИМЯ_ПОЛЬЗОВАТЕЛЯ    # затем перелогиниться
ls -l /dev/bus/usb/00X/00Y                      # проверить владельца
```

## Программы для сканирования

`scanimage` (консоль), `simple-scan`, `xsane`, `skanlite` — любая, что
говорит на SANE. Через сеть: `saned` или `scanimage --format=tiff` в
скрипте.
